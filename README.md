# LLM for Production

A project demonstrating how to implement and deploy Large Language Models (LLMs) in production environments using Ollama. Practical exercises modified from the book "Building LLM's for Production", Louis-Francois Bouchard & Louie Peters, 2024

## Overview

This project shows practical examples of:

- Data preprocessing for LLMs
- Prompt engineering techniques
- Local LLM deployment with Ollama
- Embedding generation and management
- Production-ready Python code structure

## Prerequisites

- Python 3.11+
- Ollama
- Required Python packages (see `requirements.txt`)

## Installation

1. Clone the repository:

```bash
git clone https://github.com/yourusername/llm_for_production.git
```
